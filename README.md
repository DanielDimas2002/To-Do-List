

# To-Do List - "Tá Feito!" ✅

Este é um simples aplicativo de lista de tarefas (*To-Do List*) que permite aos usuários adicionar, editar, marcar como concluído e remover tarefas. O aplicativo armazena os dados no *localStorage* para persistir as tarefas mesmo após a página ser recarregada. 📋

## Funcionalidades ⚙️

- **Adicionar Tarefas**: Os usuários podem adicionar novas tarefas com título e descrição. ✍️
- **Editar Tarefas**: Os usuários podem editar as tarefas existentes. ✏️
- **Marcar como Concluída**: Cada tarefa pode ser marcada como concluída, com a opção de visualizá-las de maneira diferenciada. ✅
- **Remover Tarefas**: As tarefas podem ser removidas da lista. 🗑️

## Como Usar 💻

1. **Adicionar Tarefa**: Preencha o título e a descrição da tarefa no formulário e clique no botão "Adicionar" para salvar a tarefa na lista. ➕
2. **Editar Tarefa**: Clique sobre a tarefa que você deseja editar e altere o título ou descrição. ✏️
3. **Concluir Tarefa**: Clique no botão de "concluir" ✅ para marcar a tarefa como concluída.
4. **Remover Tarefa**: Clique no botão de "remover" 🗑️ para excluir a tarefa da lista.
